       ** Para quem é este projeto **

Este sistema é destinado a faculdades e universidades que precisam organizar a distribuição de salas para turmas e disciplinas de forma automática, evitando conflitos de horário e otimizando o uso dos espaços da instituição.

O que ele faz

De forma simples: você informa as turmas, os horários e as salas disponíveis, e o sistema organiza tudo automaticamente, evitando que duas turmas fiquem marcadas na mesma sala no mesmo horário.
